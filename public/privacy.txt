Local Browser AI does not collect, use or share any user data.

All settings, keys and conversations are stored locally in your browser profile.
Page content is only read when you explicitly attach the current tab (from the
right-click menu, the add button in the panel, or with a question typed in the
address bar), and it is only sent to the model server you configured yourself.

The web search tool sends its query to your default search engine, exactly as if you
had typed it into the address bar. It reads the results only after you allow the
site, and that page is treated like any other page you attach.

The extension contains no analytics, no telemetry and no tracking.

It is an open source project: https://github.com/alexewerlof/local-browser-ai
